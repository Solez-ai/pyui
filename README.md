# PyUI Builder

A focused Python GUI builder for creating Tkinter and CustomTkinter interfaces with a drag-and-drop canvas.

## Developer

Made by solo developer **Samin Yeasar**.

- Website: https://solez.vercel.app
- GitHub: https://github.com/Solez-ai

## What It Does

- Build Python GUI layouts visually.
- Switch between Tkinter and CustomTkinter.
- Drag widgets onto the canvas.
- Inspect the widget tree.
- Upload local assets.
- Export generated Python code.

## Run Locally

```bash
npm install
npm start
```

## Build

```bash
npm run build
```
